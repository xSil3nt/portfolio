Agricultural robot fleet simulator

A discrete-event simulation for studying fleet size, robot ratios and charging-station capacity in heterogeneous oil-palm harvesting fleets. It models three robot roles, task allocation, batteries, drainage-aware routing and repeatable parameter sweeps.

Python · SimPy · FastAPI · React · TypeScript · SQLite

2025–2026

Full-spectrum colour mixing for OrcaSlicer

Contributed mixed-filament colour mixing and Local-Z dithering to a collaborative OrcaSlicer fork. Snapmaker later merged the co-authored work into its official Snapmaker Orca slicer, and the upstream OrcaSlicer integration credits the contribution.

Snapmaker merge Upstream integration

2025

Satellite-connected field monitoring nodes

Developed firmware for custom STM32U0 ground nodes that read field sensors over Modbus/RS-485 and transmit compact telemetry through Iridium SBD. The firmware handles low-power shutdown, sensor detection, local storage and retransmission after connectivity failures.

C++ · STM32U0 · Modbus · RS-485 · Iridium SBD · FRAM

2026

Huginn autonomous payload drone

Built the Raspberry Pi telemetry backend, WebSocket server and browser dashboard for a four-person autonomous drone project. I also worked on MAVLink integration, RealSense support and safe flight-test procedures covering failsafes, manual override and loss-of-control response.

Python · MAVLink · WebSockets · Raspberry Pi · HTML/CSS/JS

2026

Lifestitchr Atlas

A responsive deckbuilder for an original card game, with search and filtering, deck rules, starter decks, card previews, shareable URL state and an automated card-atlas generation workflow.

BlissROM for the Samsung Galaxy Note 5

Built and maintained an official Android 10 ROM for several Galaxy Note 5 variants, working with device trees, kernel and vendor sources, release builds, updates and community support. The releases passed 10,000 downloads on XDA Developers.

Armbian ports for Android phones

Ported Armbian to several Android phones to explore them as inexpensive home servers and Raspberry Pi alternatives, with their batteries acting as built-in UPS units and USB breakouts providing GPIO/UART access.

About
