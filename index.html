P.01 Simulation / Full-stack 2026 — Ongoing

Agricultural robot fleet simulator

Simulating coordinated
field robots.

01 / Problem

Three robot types. One dependent pipeline.

Langur harvesters, Howler collectors, and Mandril transporters must stay productive while sharing routes, charging capacity, and time.

02 / System

Geospatial field data drives the simulation.

A SimPy core ingests geospatial fields, generates Delaunay cells, models battery constraints, and compares Hungarian assignment against simpler baselines.

03 / Interface

Every run can be watched, repeated, and compared.

FastAPI, SQLite, React, and WebSockets turn parameter sweeps into live fleet state and decision-ready KPIs.

  • Python
  • SimPy
  • FastAPI
  • React
  • WebSockets

P.02 Embedded / IoT 2025

Satellite-connected field monitoring

Satellite telemetry for
remote field sensors.

01 / Sense

Low-power sensor-based monitoring.

Custom STM32U0 nodes detect field sensors, read registers over Modbus/RS-485, and monitor their own battery state.

02 / Survive

Store telemetry when connectivity fails.

FRAM and EEPROM fallback storage queue telemetry for retransmission, while RTC shutdown and deep sleep protect the energy budget.

03 / Uplink

Compact telemetry over Iridium SBD.

Compact packets travel through Iridium Short Burst Data. The system was validated in field deployments and documented for handover.

  • C++
  • STM32U0
  • Modbus
  • Iridium SBD
  • FRAM

P.04 Autonomy / Telemetry 2026

Autonomous payload drone

Telemetry and control for an
autonomous payload drone.

01 / Observe

Flight telemetry in a shared browser dashboard.

I built the Raspberry Pi 5 telemetry backend, WebSocket server, and browser dashboard for vehicle state, mission progress, payload status, and ArUco visualisation.

02 / Integrate

Multiplexing serial and telemetry contention.

A MAVProxy UDP multiplexer resolved serial contention, while compiled RealSense support and tuned telemetry rates kept the system responsive.

03 / Test

Manual override, abort, and loss-of-control procedures.

The team built pre-flight, override, abort, and loss-of-control procedures. Integrated payload testing recorded a 9 N peak impact.

  • Python
  • MAVLink
  • WebSockets
  • RealSense
  • Raspberry Pi
