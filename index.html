P.01 Simulation / Full-stack 2026 / Ongoing

Final-year project

Robot fleet
simulator.

01 / Problem

Harvest, collect, transport.

Langur harvesters, Howler collectors, and Mandril transporters share routes and chargers in this oil-palm harvesting simulation.

02 / System

Field model.

I built the SimPy model with geospatial field data, battery limits, and drainage-aware routing. It compares Hungarian, greedy, and field-sequential task assignment.

03 / Interface

Run comparisons.

A React dashboard shows fleet activity over WebSockets. FastAPI and SQLite store runs for comparing fleet sizes, robot ratios, and charging capacity.

P.02 Embedded / IoT 2025

Averis internship

Satellite-connected
field sensors.

01 / Sensor nodes

Battery-powered sensor nodes.

I wrote C++ firmware for STM32U0 nodes that read water-level sensors over Modbus/RS-485 and monitor battery charge.

02 / Offline storage

Store now, send later.

Unsent readings stay in FRAM and EEPROM until the next connection. RTC shutdown and deep sleep save power between readings.

03 / Uplink

Satellite uplink.

The nodes send readings through Iridium Short Burst Data. I tested them in the field and wrote the handover documentation.

  • C++
  • STM32U0
  • Modbus
  • Iridium SBD
  • FRAM
