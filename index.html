P.01 Simulation / Full-stack 2026 / Ongoing

Agricultural robot fleet simulator

Simulating coordinated
field robots.

01 / Problem

Harvesters need collectors to keep up.

Langur robots harvest, Howler robots collect, and Mandril robots transport the crop. The simulation models how they share routes and chargers while waiting on each other's work.

02 / System

Modelling the field and the fleet.

I use SimPy to model the fleet, with Delaunay cells generated from geospatial field data. The model tracks battery limits and compares the Hungarian assignment algorithm with simpler methods.

03 / Interface

Watching a run and comparing the results.

A React dashboard shows the fleet state over WebSockets. FastAPI and SQLite handle the simulation runs and results, so I can change parameters and compare performance.

  • Python
  • SimPy
  • FastAPI
  • React
  • WebSockets

P.02 Embedded / IoT 2025

Satellite-connected field monitoring

Satellite telemetry for
remote field sensors.

01 / Sensor nodes

Reading sensors on a battery budget.

Custom STM32U0 nodes detect field sensors, read registers over Modbus/RS-485, and monitor their own battery state.

02 / Offline storage

Keeping readings when the connection drops.

The nodes queue unsent readings in FRAM and EEPROM for the next connection. RTC-controlled shutdown and deep sleep reduce power use between readings.

03 / Uplink

Compact telemetry over Iridium SBD.

The nodes send compact packets through Iridium Short Burst Data. This work included field validation and handover documentation.

  • C++
  • STM32U0
  • Modbus
  • Iridium SBD
  • FRAM

P.04 Autonomy / Telemetry 2026

Autonomous payload drone

Telemetry and control for an
autonomous payload drone.

01 / Dashboard

Seeing what the drone is doing.

I built the Raspberry Pi 5 telemetry backend, WebSocket server, and browser dashboard for vehicle state, mission progress, payload status, and ArUco visualisation.

02 / Integration

Sharing one telemetry connection.

I used MAVProxy to share telemetry over UDP and resolve conflicts over the serial connection. I also compiled RealSense support and adjusted telemetry rates to keep updates responsive.

03 / Test

Planning for a flight to go wrong.

Our team wrote pre-flight checks and procedures for manual override, aborts, and loss of control. Payload testing recorded a peak impact force of 9 N.

  • MAVLink
